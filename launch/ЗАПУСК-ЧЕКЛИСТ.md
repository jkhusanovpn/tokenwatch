# Чеклист запуска TokenWatch

Всё подготовлено; пункты ниже требуют ваших аккаунтов/оплаты — это делаете вы (я помогу командами).

## 1. Внешние аккаунты (один раз)
- [ ] GitHub-репозиторий: `gh repo create tokenwatch --public --source . --push` (из папки tokenwatch). Если ник не javoxir — скажите, поправлю ссылки в README/лендинге/постах.
- [ ] npm: `npm login`, затем `npm publish` (пакет `tokenwatch-sdk`, prepublishOnly соберёт dist автоматически)
- [ ] PyPI: `pip install build twine && cd python && python -m build && twine upload dist/*` (пакет `tokenwatch-sdk`)
- [ ] Домен: зарегистрировать **gettokenwatch.com** (свободен на 12.06.2026), задеплоить `site/` на Vercel/Netlify/Cloudflare Pages (статический HTML, ноль конфигурации)

## 2. Перед публикацией постов
- [ ] Прогнать quickstart с нуля на чистой папке: `npx tokenwatch-sdk serve` после публикации npm
- [ ] Скриншот дашборда с демо-данными → в README и в посты
- [ ] В README заменить заглушку https://github.com/jkhusanovpn/tokenwatch на реальный URL (если отличается)

## 3. Запуск (порядок и тайминг)
1. [ ] **dev.to** — `launch/dev-to-post.md` (миграционный угол «Helicone alternative» — это живой поисковый трафик прямо сейчас)
2. [ ] **Show HN** — `launch/show-hn.md`, вт-чт 14:00–16:00 UTC, первые 3-4 часа сидеть в треде и отвечать всем
3. [ ] **X-тред** — `launch/x-thread.md`, в тот же день что HN
4. [ ] Reddit r/LocalLLaMA + r/SideProject — короткая версия dev.to поста (не копипаста, под культуру сабреддита)
5. [ ] Product Hunt — через 1-2 недели, когда будут первые звёзды/фидбек

## 4. После запуска
- [ ] Отвечать на каждый issue/комментарий в первые дни — это и есть маркетинг
- [ ] Собрать жалобы → роадмап v0.2 (Python streaming, regression-алерты)
- [ ] Лист ожидания cloud-версии на лендинге (email-форма)

Окно «Helicone alternative» видно всем — LLMeter и Torrix уже в нём. Скорость важнее полировки: лучше запустить v0.1 на этой неделе, чем v0.3 через месяц.
